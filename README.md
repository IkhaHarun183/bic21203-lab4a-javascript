## Lab 4b: Client-Side Scripting (JSON and jQuery)

### Lab Overview
This laboratory focuses on JSON data handling, the Fetch API, and jQuery DOM manipulation.

### Question 1: Create and Structure JSON Data
Created a valid `books.json` file containing two book objects:
- The Great Gatsby
- To Kill a Mockingbird

Each book contains its title, author, publication year, and genres.

### Question 2: Retrieve and Display JSON Data
Used the JavaScript Fetch API to retrieve data from `books.json` and display:
- The title of the first book.
- The author of the second book.
- The genres of both books.

### Question 3: Compare Native JavaScript and jQuery
Used jQuery 4.0.0 to perform three DOM operations:
1. `.text()` to modify text content.
2. `.addClass()` to apply CSS styling.
3. `.on("click")` to handle button click events.

**Evidence:** Screenshots are included in the Lab4b-JSON-jQuery folder.
