### Lab Overview
This laboratory focuses on client-side scripting using JSON, modern JavaScript, and jQuery. It demonstrates how to create JSON data, retrieve and display information using the Fetch API, and manipulate HTML elements using jQuery.

### How to Run
1. Open the project folder in Visual Studio Code.
2. Install and enable the Live Server extension.
3. Open `books.html` or `jquery-dom.html`.
4. Right-click and select **Open with Live Server**.
5. Test the functionality in your browser.

This laboratory provided practical experience in handling JSON data and manipulating webpage elements using JavaScript and jQuery. The Fetch API allows asynchronous data retrieval, while jQuery provides convenient methods for DOM manipulation and event handling.
